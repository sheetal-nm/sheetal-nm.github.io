THE CORE CHALLENGE

The homepage and navigation carried the highest design pressure. They needed to establish a new visual identity while also making a very large services website easier to understand and maintain.

03

KEY DESIGN DECISIONS

Three areas shaped the experience of the entire website.

01 / BANNER

Make the first screen communicate confidence, not clutter.

The homepage banner became the first expression of the new direction. The goal was to move away from the older boxed presentation and establish stronger hierarchy, more breathing room, and a clearer entry point into Softlabs’ services.

  • Stronger visual hierarchy for primary messaging
  • More contemporary spacing and typography
  • Clearer path toward service discovery
  • Responsive behaviour considered from the start

02 / NAVIGATION

Navigation had to support the scale of 200+ pages.

Because Softlabs covers many services, solutions and technologies, the navigation could not be treated as a simple header. I explored multiple structures and visual options before settling on a system that could grow with the website.

  • Grouped related offerings instead of presenting one flat list
  • Designed the header as a reusable global component
  • Balanced discoverability with visual simplicity
  • Considered desktop and responsive navigation behaviour

DESIGN AT SCALE

Consistency became a frontend architecture problem too.

With more than 200 pages, repeating the same UI manually would have made the site harder to maintain. I created reusable PHP sections so shared content patterns could stay visually consistent.

01

Testimonials

Shared section design, content changes per page.

02

Clients

Reusable visual block across relevant pages.

03

Technology

Consistent structure for technical capabilities.

04

Common service presentation with flexible content.

06

OUTCOME

A website that could evolve without redesigning every page from scratch.

The redesign moved Softlabs away from its older box-heavy presentation toward a more contemporary, structured and reusable website experience.

The strongest learning was scale: a homepage can look good in isolation, but on a 200+ page website the navigation, reusable sections, responsive rules and implementation choices determine whether the design can actually survive in production.

MY TAKEAWAY

Designing the system around the page was just as important as designing the page itself.
